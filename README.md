# 电视媒体轮播 / TV Media Carousel

Kotlin Android TV 工程，minSdk **23**，compileSdk / targetSdk **34**，无需 root。原生 View 遥控器界面，Media3 视频、Glide 图片、JSON 媒体索引、SAF U 盘目录和内置局域网 HTTP 服务。依赖下载只发生在开发构建时，安装后的播放和上传均不需要外网。

## 编译和安装

需要 JDK 17（也可用支持 Gradle 8.7 的 JDK 21）、Android SDK Platform 34、Build Tools 34.0.0。Android Studio 打开工程根目录，等待 Gradle 同步；或：

```sh
# 设置本机 SDK 路径，勿直接沿用开发容器路径
printf 'sdk.dir=/your/android-sdk\n' > local.properties
./gradlew assembleDebug testDebugUnitTest lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Windows 使用 `gradlew.bat`。首次构建需要访问 Google Maven、Maven Central 和 Gradle。Debug APK 使用调试证书；正式分发请在本机配置自己的 release keystore，切勿提交私钥。依赖版本固定在构建文件中。

## 首次使用

1. 从电视应用列表打开“电视媒体轮播”，允许媒体读取权限；Android 13+ 还会请求通知权限。拒绝媒体权限仍可播放本地上传文件。
2. 空库显示上传地址、首次设置 PIN 和操作提示。有媒体时按菜单键，或长按确认键 1.5 秒进入设置。首次 PIN 同时显示在首次登录页，每台安装随机生成六位数字。
3. 设置内修改**设置 PIN**和**上传 PIN**，两者独立。设置 PIN 修改后不再显示初始提示；上传 PIN 可在受保护设置内查看。丢失设置 PIN 需通过系统清除 App 数据重置，这也会删除本地媒体。
4. 连接与电视相同的 WiFi / 有线局域网，手机访问设置页的实际地址或扫码，输入上传 PIN 后连接。选择多个文件，点击上传。上传成功即加入播放列表；当前文件播放完后会播放新增文件。
5. U 盘默认导入 App 内部私有目录。Android 11+ 推荐先在设置选择“授权 U 盘目录”，选中具体分区目录并授权。拔出 U 盘后本地副本继续播放。多 U 盘 / 分区可分别授权。
6. 调整方向、图片秒数、排序、静音等；返回播放即应用，方向立即生效。播放页吞掉返回键，避免误退出。Home、系统设置和系统强制停止仍由 Android 管理，本 App 不是设备所有者 kiosk。

## U 盘和权限兼容

- API 23–32：动态 `READ_EXTERNAL_STORAGE`；API 33–34：`READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO`；API 34 另请求 `READ_MEDIA_VISUAL_USER_SELECTED`，允许部分授权，扫描仅包含当前可见媒体，回到播放页重新扫描。不申请 `MANAGE_EXTERNAL_STORAGE`，不申请 root。
- SAF 持久化读权限是受限存储下的首选。已授权分区优先使用 SAF，避免与同分区挂载路径 / MediaStore 重复导入。固件暴露方式不一致时仍可能存在重名副本，可在网页删除本地副本。
- API 30+ 使用 `StorageManager.storageVolumes` 获取可移动卷；可读 `/storage/XXXX-XXXX` 目录和 API 29+ 可移动 MediaStore 卷作为兜底。API 23–29 自动发现常见 UUID 挂载路径；非标准厂商路径请用 SAF 手动授权。
- 无法绕过厂商禁用文件选择器、禁止读取 U 盘或不支持文件系统的限制。FAT32 单文件本身限制约 4 GB；exFAT/NTFS 是否可读取取决于固件。
- 过滤隐藏文件、Android、System Volume Information；递归深度最多 12 层、每次最多 20,000 个媒体项，防止异常目录无限扫描。扫描运行于串行后台执行器。
- 默认缓存使用源 URI、大小、修改时间去重。源文件修改会生成新缓存；旧副本不会自动删除。跨授权方式或缓存 / 直接模式切换后建议清理副本再重新扫描。
- 关闭“U 盘复制到本地”后，新扫描的外部项目直接播放。已导入副本保留；若只想直接播放，先清空本地库。热拔出会触发刷新，解码 / IO 错误跳过。未被系统报告的拔出最迟通过播放器超时或手动刷新恢复。
- 开机延迟扫描、媒体挂载广播、30 秒补扫共同处理慢挂载。无法读取的目录记入日志；拒绝权限不会导致整个 App 退出。

## 播放和方向

图片：JPG / JPEG / PNG / WebP，Glide 按屏幕尺寸采样解码，处理 EXIF；不启用 GIF。视频：优先 MP4 / H.264，也接受 M4V / MKV / WebM，能否解码由设备决定；HEVC 需要设备提供解码器。Media3 按设备能力选择解码器并处理容器旋转元数据。所有格式均需目标电视实测。

图片可设置 3–60 秒，顺序或随机，自然文件名 / 修改时间升序 / 加入时间排序，列表循环或播放一轮；单视频循环启用后会停留在当前视频。支持静音、适应屏幕 / 居中裁剪和可关闭的淡出 / 淡入。损坏文件跳过；整轮失败后等待 30 秒重试；视频连续 90 秒没有播放进度则跳过。

四方向统一使用根布局旋转并交换 90° / 270° 的逻辑宽高，避免依赖电视是否允许 Activity 改变系统方向。视频用 TextureView；播放、空库、数字键盘和设置页面都在同一旋转容器中。方向键进行反向坐标映射。**系统权限框、系统文件选择器、系统设置和系统输入法由固件控制方向**，App 无权旋转这些外部界面。HTTP 网页不随电视旋转。

## 上传服务

- 前台服务持续提供上传，默认端口 8080，可设 1024–65535；占用时在后续最多 10 个端口中尝试，始终以电视显示的实际地址为准。无可用端口时提示并每 10 秒重试。
- 仅绑定系统标记为 WiFi / Ethernet 网络上的私有 IPv4 地址，不绑定所有接口；网络切换每 10 秒检查并重新绑定。IPv6-only、访客 WiFi 终端隔离、VPN-only 网络暂不支持。
- 网页使用 XMLHttpRequest 原始文件流，逐个上传并显示进度。服务使用 Long 长度和 128 KiB 缓冲区，单文件上限 16 GiB，预留 64 MiB 空间；支持超过 2 GiB 文件。临时 `.part` 不进入媒体库，中断即删除，提交前 `fsync`，重启清理遗留临时文件。
- 仅接受已知 Content-Length 的原始文件请求，不支持 multipart / chunked / 断点续传。最多两个并发请求、两个排队连接；读空闲超时 60 秒。网页文件名通过 DOM textContent 展示，服务端随机生成存储文件名。
- 页面本身可公开读取；列出文件、上传、删除、刷新 API 都需 X-PIN。五次认证失败后全局暂停认证 30 秒；设置 PIN 入口同样限流。检查 Host / Origin，拒绝跨站请求；不启用 CORS。
- PIN 摘要用于验证；上传 PIN 为便于受保护设置页显示，也存放于 App 私有偏好中。PIN 和文件经 HTTP 明文传输，仅在可信内网使用。不提供公网映射 / UPnP。请勿在路由器上把该端口转发到公网。
- 文件按扩展名接受，真实解码在电视端进行；伪装或损坏媒体会记录并跳过。未加入病毒扫描或浏览器视频转码。
- 端口和上传开关由前台服务重新检查；设置返回播放后十秒内更新，关闭上传不会关闭轮播。

## 开机、自启动和恢复

Manifest 声明 `BOOT_COMPLETED`、`MY_PACKAGE_REPLACED`，按开关启动前台服务，再延迟尝试打开播放界面。需**安装后至少手动打开一次**；系统强行停止后，在用户再次打开前通常不会收到开机广播。

Android 10+ 对后台打开 Activity 有限制，Android 12+ 对后台启动前台服务有限制；厂商还可能拦截开机广播。广播 / 服务并不能保证所有电视自动弹出播放器。**无人值守部署请优先在设置启用默认桌面入口，进入系统桌面设置选择本 App，并配置厂商自启动 / 后台白名单。** Android Go、某些定制固件和商用设备策略可能有额外限制。关闭自启开关只控制开机广播；若仍是默认桌面，按 Home / 系统启动仍会进入 App，需另行关闭默认桌面入口并选择系统桌面。

API 34 前台服务使用 `specialUse`：用于长时离线电视展示和用户启用的局域网文件接收，声明子类型及对应权限。若分发 Google Play，需要按实际产品用途审核 specialUse 的政策资格。此工程不滥用 dataSync 来规避未来版本的同步时限。

Activity 设置 `FLAG_KEEP_SCREEN_ON` 和沉浸模式。进程崩溃时写滚动日志并安排尽力而为的非精确恢复闹钟，十分钟最多三次，避免崩溃循环；Service 为 START_STICKY。Android 后台限制、强制停止和厂商杀进程仍可能阻止恢复。没有 root / 设备所有者权限，无法承诺无条件拉起进程。视频无进度看门狗不等同于系统级 ANR 监控。

## 日志、界面和测试

日志在 App 私有目录滚动保存：当前 / 上一份各约 1 MiB。设置可查看最近 60 KB，并通过系统文档选择器导出到 U 盘。服务器日志不记录 PIN。JSON 索引使用临时文件 rename 替换；索引异常时可通过扫描重建本地项目，原始上传文件名可能丢失。
