# 1.1.1 遥控器焦点修复

本次按用户要求仅修改源码并运行 `:app:assembleDebug` 编译 APK，未运行单元测试、Lint、模拟器或界面测试。构建成功；实际遥控效果由用户验证。1.1.0 的测试报告与截图是历史记录，不代表 1.1.1 已通过测试。

## 修改

- 所有按钮统一使用金黄色背景、深色文字和白色边框表示焦点；绿色表示当前页签 / 主要操作，二者不再混淆。
- 设置开关与数字输入框加入相同焦点提示，避免只有默认细线或滑块变化。
- 设置页底部常驻“当前焦点”文字，获得焦点的控件自动滚动到可见区域。
- 页签切换、方向修改、数值保存后恢复对应控件；媒体网格刷新保留原项目焦点，原项目移除时选择相邻项目，空库回到可用操作。
- 图片封面保留触控入口，遥控焦点统一落在文件按钮上；播放器画面与视频内部视图不再成为隐藏焦点。
- 顶部页签与播放控制按钮明确左右移动边界；播放控制栏聚焦期间不自动消失，返回键可收起。
- 媒体详情、数值编辑等子页面按返回键回到设置工作台。

## 安装

版本号 1.1.1 / versionCode 3，包名不变。使用与上次 1.1.0 相同的调试签名配置，可用于更新上次交付的版本。原仓库 1.0.0 签名不同的问题仍然存在。
