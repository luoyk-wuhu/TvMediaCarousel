# 1.1.2 顶部页签与旋转屏方向键修复

根据用户实机照片：顶部焦点在“文件夹”，内容仍停留在“媒体库”。本次修改为遥控器左右键直接同步切换页签与内容；不再要求先移动焦点再按确认。

- 顶部页签显式处理左右键，焦点与当前内容保持一致；聚焦其他页签时也同步选择该页。
- 下键进入当前页第一个操作，上键从第一个操作返回当前选中的页签。
- 移除根布局按旋转角度反向映射方向键的处理。无论显示方向为 0 / 90 / 180 / 270 度，遥控器方向始终与界面文字的阅读方向一致。
- 保留 1.1.1 的金黄色白边焦点、底部焦点文字、焦点恢复和播放控制栏常驻逻辑。

版本 1.1.2 / versionCode 4。只运行 `:app:assembleDebug`，构建成功；按用户要求未运行单元测试、Lint、模拟器或实机测试。实际效果由用户验证，历史 1.1.0 测试结果不代表本版本已经测试。

沿用上次交付的调试签名配置。源码、APK、源码 ZIP 和校验文件随本次提交同步到 GitHub。原仓库 1.0.0 的调试签名不同，覆盖升级需原签名或先备份数据。
