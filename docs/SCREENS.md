# 关键页面说明

本交付提供页面说明；未将未运行的设计稿作为真机截图。

1. **播放页**：黑色全屏背景；图片和视频按比例居中显示，可选择裁剪。默认隐藏系统栏、静音、常亮；返回键被拦截。按菜单或长按确认键进入 PIN 页。
2. **空媒体页**：居中显示插入 U 盘 / WiFi 上传提示、实际访问地址、扫描状态、设置入口和首次初始化 PIN。无网络时提示没有 WiFi / 有线局域网。
3. **设置登录页**：旋转容器内数字键盘；方向键选数字、确认输入；退格、清除、确认、返回。错误有反馈，连续五次错误冷却三十秒。
4. **设置页**：深色纵向滚动列表，绿色粗边框标识焦点。顶部显示地址、二维码、服务状态与上传 PIN。依次为播放、方向、USB、上传、PIN、自启、系统引导和日志设置。
5. **数值 / PIN 编辑页**：同样使用遥控器屏幕数字键盘；数值校验失败留在页面，显示允许范围。方向切换后整个界面即时旋转。
6. **清空确认页**：默认焦点在取消，另有确认清空；不会在单次误按后删除整个媒体库。
7. **手机上传页**：适配窄屏，PIN 输入、多选文件、逐文件进度条、空间提示、文件列表和删除确认。长文件名自动换行，错误以文本显示。
8. **日志页**：最近 60 KB 文本；导出使用系统文件保存界面，可选择 U 盘。系统外部界面的方向取决于电视固件。
